# Spare Autos website

This is a static site: open `index.html` in a browser, or upload the whole folder to any host (Netlify, GitHub Pages, Hostinger and so on). There is no build step.

## Before going live, fill in
- **WhatsApp / phone:** replace `91XXXXXXXXXX` (in `index.html` twice and in `script.js` once) and `+91 XXXXX XXXXX` (in `index.html` twice).
- **Addresses:** the full street addresses for Mumbai and Delhi (in the Locations section of `index.html`).
- **Brand badges:** check the labels (Authorised distributor, Direct import and so on) in the Brands section.

## Enquiry form
There's no server. "Email enquiry" opens the visitor's email app with the enquiry pre-filled, addressed to spareautos2025@gmail.com. "Send on WhatsApp" opens WhatsApp with the same text.
